周一的日常

发表于 2026-11-02 更新于 2026-11-03 分类于 日常
一天里值得留下的碎片，顺便记一下这个模板该怎么填。

今天把博客彻底跑通了。这篇既是日记，也是一个可以照着抄的模板。

今天做了什么

早上翻了一遍博客的配置，中午把评论接通，晚上回来写这篇。

三件事里最耗时的其实是最后一件——不是写字慢，是不知道该写什么。

写作最难的部分不是表达，是决定要不要说。

所以打算换个策略：不追求每篇都有主题，先按天记，凑够几篇再回看，有值得展开的单独拎出来写成长文。

几条随手记

  • 主题的深色模式比想象中好看，晚上看不刺眼
  • pathname 这个评论匹配方式比标题稳，改标题不会丢评论
  • 代理只在发布时需要开，写作过程完全离线

点开看今天踩的坑

部署时 .nojekyll 一直没推上去，查了半天才发现是 hexo-fs 复制目录默认忽略隐藏文件。
在 _config.yml 的 deploy 段加 ignore_hidden: false 就好了。

这种坑不写下来，下次一定还会踩。
